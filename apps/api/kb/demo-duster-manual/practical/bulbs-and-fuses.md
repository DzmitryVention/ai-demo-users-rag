**Lights.** Check regularly that all exterior lights work. Many lights on modern vehicles use LEDs that cannot be replaced individually: if one fails, have it checked by a workshop. Where bulbs can be changed, the official manual shows the bulb type and procedure.

**Fuses.** If an electrical item stops working, a fuse may have blown. The fuse boxes are typically located under the dashboard and in the engine compartment; a label shows which fuse protects which circuit. Replace a blown fuse only with one of the same rating.

> **WARNING:** Never replace a fuse with one of a higher rating or bridge it with wire; this can cause a fire.

> **NOTE:** If a new fuse blows again immediately, there is a fault in the circuit. Have it checked by a workshop.
