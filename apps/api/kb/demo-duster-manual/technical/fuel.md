Use only the fuel type indicated on the label inside the fuel filler flap and in the official manual. Petrol and diesel engines must never be filled with the wrong fuel.

**Refuelling.** Switch off the engine. Open the fuel flap and the cap, insert the nozzle fully and stop filling when the nozzle cuts off automatically for the first time. Do not top up beyond this point.

**Wrong fuel.** If you have put the wrong fuel in the tank, do not start the engine — not even switch on the ignition. Have the tank drained by a professional.

> **WARNING:** No smoking, open flames or phone calls near the vehicle while refuelling.

> **NOTE:** Some diesel versions use an exhaust additive (AdBlue). A message on the display tells you when it needs refilling; see the official manual for the procedure.
