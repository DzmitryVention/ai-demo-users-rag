**Starting.** Make sure the gear lever is in neutral (or P on an automatic gearbox). Press the clutch pedal fully (manual gearbox) or the brake pedal (automatic gearbox), then turn the key or press the start button. Release it as soon as the engine starts.

If the engine does not start after a few seconds, wait a moment before trying again; repeated long attempts can drain the battery.

**Stopping.** Stop the vehicle, apply the parking brake, put the gearbox in neutral (or P) and switch off the ignition.

**Stop and Start.** Some versions switch the engine off automatically when the vehicle is stationary, for example at traffic lights, and restart it when you press the clutch or release the brake. The system can be deactivated with a button on the dashboard.

> **WARNING:** Never run the engine in a closed space such as a garage: exhaust gases are toxic.

> **WARNING:** Never switch off the ignition while the vehicle is moving. Braking and steering assistance would stop working.
