Versions with an automatic gearbox have a selector with the positions **P** (park), **R** (reverse), **N** (neutral) and **D** (drive). Some versions also allow manual gear selection.

- Press the brake pedal before moving the selector out of P.
- Select R or D only when the vehicle is stationary.
- When parking, select P and apply the parking brake.

If a gearbox warning message appears, reduce your speed and drive gently to a workshop. If the warning is accompanied by loss of drive, stop safely and call for assistance.

> **WARNING:** Never leave the vehicle with the engine running and the selector in D or R.

> **NOTE:** Do not hold the vehicle on a slope using the accelerator; use the brake.
